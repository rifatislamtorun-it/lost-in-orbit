Drop PLAYER_CHARACTER.glb in this folder (path set in src/config/game.config.js).
Animations are auto-detected by clip name: Idle, Walk, Run, Jump, Fall, Interact, Wave, Celebrate, Sad, Repair, UseTool, Point, Scan, Damage.
Missing clips fall back gracefully. Model is auto-scaled to CONFIG.player.height and should face +Z.

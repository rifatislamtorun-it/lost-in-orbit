Drop MARS_COLONY.glb in this folder (path set in src/config/game.config.js).
Name objects (or give them a custom property "tag") like: Habitat, SolarArray, WaterExtractor, OxygenGenerator, Greenhouse,
ResearchLab, RepairStation, Antenna, LandingZone, DustStormZone, RadiationShelter, Rover, Mountain, Crater, Volcano.
Matching is case-insensitive and ignores _ - spaces; extra aliases live in OBJECT_MAP. Missing objects never crash the game.
